    A slide is function (ctx, t, s)

    It is called once per frame. Draw the whole picture every call, from t alone — no state kept between calls, no Math.random, no clock. That is what makes the preview, the thumbnails and every exported frame the same picture.

    ctx
    A 2D canvas context. 0..s.w × 0..s.h is the post, whatever size the preview or export is.
    t
    Loop progress, 0 → 1, then it wraps. Anything that spins or ripples should do so a whole number of times per loop so the last frame lands on the first.
    s.w, s.h
    The format's size in pixels (1080 wide).
    s.seconds, s.fps, s.frame
    Loop length, frame rate, current frame index.
    s.index, s.count
    This slide's position and how many slides there are.
    s.TAU
    2π.

    Timing

    s.span(t, from, to, ease?)
    0 before from, 1 after to, eased between.
    s.stagger(t, i, n, {from, to, overlap, ease})
    Progress of item i of n, each window overlapping the next (overlap 0..1, default 0.6).
    s.ping(t)
    0 → 1 → 0, a triangle over the loop.
    s.wave(t, cycles)
    0 → 1 → 0, smooth, a whole number of times per loop. Always seamless.
    s.ease.*
    linear in out inOut quadIn quadOut expoIn expoOut backIn backOut elasticOut bounceOut
    s.wrap(t)
    t modulo 1.

    Numbers

    s.clamp(v, a, b), s.lerp(a, b, t), s.map(v, a, b, c, d)
    The usual.
    s.rand(seed)
    A seeded generator: const r = s.rand(7); r(); r(); — identical every frame.
    s.hash(i, seed?)
    One stable number in 0..1 for an index.

    Text and paths

    s.lines(text, maxWidth)
    Word-wraps with the current ctx.font; returns lines. \n forces a break.
    s.fit(text, maxWidth, {max, min, weight, family})
    Largest size at which the text fits one line. Sets ctx.font, returns the size.
    s.circle(x, y, r), s.roundRect(x, y, w, h, r)
    Begin a path; you fill or stroke it.
    s.font({size, weight, italic, family})
    Builds a ctx.font string. Archivo also has a width axis: set ctx.fontStretch = "condensed", or pass stretch to s.rich.
    s.rich(text, x, y, {size, weight, family, align})
    One line where *word* is italic, **word** bold and __word__ underlined, mixing faces in a line. Returns its width; s.measure measures without drawing.
    s.justify(text, x, y, width, spread)
    Spreads a line's words across width; spread 0 packs them, 1 justifies.
    s.layer(name)
    A cleared offscreen {canvas, ctx} the size of the post, for something you will warp or mask.
    s.warp(canvas, {slice, dx: v => …, sx: v => …})
    Draws a layer in horizontal slices, each shifted and stretched, v = 0 at the top, 1 at the bottom.
    s.grit(canvas, {texture, grain, chunk, rough, bleed, chroma, boil, t, seed, hard})
    Draws a layer through the grit shader, like a screen print: texture is how much the paper's tooth eats into the ink (0..1.5, inside the shape as much as at its edge), grain blends the tooth from coarse mottle (0) to fine speckle (1), chunk is the speckle cell (px), rough is a small wobble of the outline (px), bleed thickens (+) or thins (−) the shape (px), chroma misregisters the colour plates (px), each on its own tooth, boil re-rolls the noise that many times per loop.
    s.on(ctx2)
    The same stage drawing into another context, so the text helpers work on a layer: const g = s.on(L.ctx).

    Options

    A slide declares what can be changed from the Options tab by asking for the value as it draws. Each call returns the current value, and the panel builds a control for it:

    s.color("Ink", "#000000")
    A colour, with the club's swatches.
    s.range("Shake", 0.3, 0, 1)
    A slider.
    s.pick("Entrance", "rise", s.ENTRANCES)
    A choice.
    s.toggle("Footer", true)
    On or off.
    s.text("Headline", "…")
    Copy. A default with line breaks gets a multi-line field.

    Motion

    s.enter(name, p, size)
    A named entrance (rise drop pop slide spin fade none, listed in s.ENTRANCES) at progress p, as {dx, dy, scale, rot, alpha}.
    s.place(x, y, fx, () => …)
    Draws under that transform, at (x, y).
    s.shake(t, seed, cycles)
    A smooth seeded shake, {x, y} in about −1..1, a whole number of cycles per loop.
    s.jitter(t, i, steps)
    A stepped random offset per item, new every 1/steps of the loop.
    s.step(t, n)
    t in n steps.
    s.scramble(text, p, t)
    The first p of the text settled, the rest churning through random letters.

    Fonts and Shared

    Two faces, loaded from Google Fonts: Archivo (sans, weights 100–900, with italics) and Lora (serif, 400–700, with italics). Nothing else.

    The Shared tab runs before every slide, so its consts and functions are in scope in each one. The default one carries the palette, the two faces, the fifteen backgrounds (confetti, tape, stripes, checker, crosses, rings, dashes, rays, burst, ribbons, polygons, strings, bricks, network, blobs) and the boxed type helpers (box, pill, tag, echo, footer).

    Files

    The post autosaves in this browser. Save writes it as a .json file, Open… reads one back, Copy link puts the whole post in the URL. PNG and All PNGs take the current instant of the scrubber. Video records one loop of this slide; Reel records every slide in order, one loop each, into one file. Recording runs in real time.
